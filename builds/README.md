# Builds

One directory per Roblox build:

```
builds/README.md
builds/ACTIVE                                one line: the directory to use
builds/version-4ea8e85481e34f46/
  build.json             client + loader build ids, core offsets, payload hash,
                         live client exe hash/size
  loader.offsets.json    header, entry, .text/.pdata, 900 import slots, TLS, patch sites
  core.offsets.json      FakeDataModel, RawScheduler, OpcodeLookupTable, TaskDefer, ...
  payload.7z             optional local copy, generated by tools/repack (not committed)
```

Rules:

- `builds/ACTIVE` names the pinned build. Loader CMake and the desktop
  `build.rs` both read it, so bumping the client is a one-line change plus a
  new `version-<hash>/` directory.
- The desktop binary embeds the pinned build/version and flags a mismatch in
  the title or status bar when the attached session reports another build.
- `payload.7z` is generated by `tools/repack`, never edited by hand.
- The loader CMake reads `build.json` at configure time, refuses a `kBuildId`
  mismatch, and embeds `builds/version-<build>/payload.7z` when it exists.
  Without the archive the proxy is fail-open-only unless `ZEND_PAYLOAD_BIN` is
  set.
- On a client bump, write the new directory name to `builds/ACTIVE` and update
  `kBuildId`/`config.h` + `offsets.h`; `offsetdump` and `repack` regenerate the
  rest.
- CI compares payload SHA-256 and byte size against the manifest.

## 4ea8e85481e34f46 (0.747.0.7471481)

```
image        0x94C2000 live / 0x94CC000 decrypted
entry        0x94C0004 -> client main 0x5FCBF1C
.text        0x66167DC virtual, 0x6617000 raw (0x824 pad trimmed)
.pdata       0x43B52 entries (277330), at 0x8FCF000
imports      900 (899 real + RobloxPlayerBeta.dll!run proxy)
lua          0x42D3C00      idJson  0x2F0FC10
payload      110374844 bytes (0x6942FBC)
sha256       2d27024c6fa1cba76cf0487f2509be988aff07e7e106641b36c795a7dc0619df
```

The Hyperion live client dump is canonical for core RVAs; the Credoxy header is
a second opinion and `offsetdump` aborts if the two disagree. `FireTouchInterest`
stays `0x14D0000` from Hyperion; Credoxy's `0x1597020` is a different function.

Payloads are large (~110 MB). If one is ever checked in, use Git LFS:

```
git lfs install
git lfs track "builds/**/payload.7z"
```
